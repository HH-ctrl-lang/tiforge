# TiForge Harness 外环

这个模块读取运行归档中的候选设计和审查证据，生成待团队复核的改进提案。当前实现覆盖正式方案中的失败挖掘与提案阶段，使用 Python 标准库，可离线运行。

## 运行首条规则

在仓库根目录执行。参数是任意一份 Run 归档的目录路径。

```powershell
python -m harness.propose_change .\logging\archive\tf-20261120-193722-f12f8512417e
```

命令从归档读取两个文件：

| 文件 | 用途 |
| --- | --- |
| `manifest.json` | 提供 Run ID、用例 ID、工作流版本和 Harness 版本。 |
| `nodes.jsonl` | 提供需求解析、候选设计和审查的节点输出。 |

首条规则只检查成本约束任务。它按候选 ID 对齐设计理由和审查风险提示，寻找缺少价格或成本依据的确定性成本排序。命中时向标准输出写一条 JSON 提案，记录证据原文、节点 ID、建议改动、预期效果和可能的副作用。无匹配证据时正常退出，标准输出为空。

## 提案如何进入回归

团队先复核提案证据，再按正式方案冻结回归用例、独立评价标准、物理守门规则、预算和比较条件。候选版本先跑相关回归子集，再跑完整固定基准，由独立评测决定晋升或回滚。当前命令的产物是待复核提案。
